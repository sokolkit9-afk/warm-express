# Тёплый экспресс 🚂🎄

Уютная новогодняя пиксельная игра. Маленький паровоз Санты развозит подарки по заснеженным городкам, собирает детские письма и бесплатно подвозит тех, кому нужно к близким.

Здесь нет врагов, таймеров и проигрыша, только дорога, снег и добрые дела.

## Управление

| Клавиша | Действие |
|---|---|
| → / D | ехать вперёд |
| Пробел (удерживать) | ехать и ускоряться; в диалоге — дальше |
| ← / A | тормозить; если поезд стоит, ехать назад |
| ↓ / S | остановиться |
| E / W / ↑ (или 1–3) | действие на станции |
| Клик мышью по препятствию | убрать сугроб или камни (несколько кликов) |
| H | праздничный гудок (жители машут) |
| Tab | журнал: маршрут, письма, пассажиры |
| Esc | меню и пауза: язык, звук, весь экран, управление, начать заново |
| M | звук вкл/выкл |

На телефоне и планшете всё делается касаниями: стрелки и кнопка ускорения «»» на экране, тап по препятствию.

## Как играть

Поезд сам не останавливается: тормозите у платформы, иногда нужно сдать назад. Если на рельсах сугроб или камни, остановитесь и кликайте по препятствию.
Если врезаться, выпадет подарок (он вернётся к Санте) или письмо (оно вернётся в свой ящик), и за ним придётся заехать ещё раз.
Цель: собрать 3/3 подарков и 3/3 писем, довезти пассажиров и вернуться к Санте.

## Языки

English (по умолчанию при первом запуске), 中文, Русский, Українська, Deutsch, Français, 日本語. Язык меняется в меню (Esc) или кнопкой на титульном экране, выбор запоминается.
Все тексты лежат в `i18n.js`: в каждой строке 7 переводов по порядку en, zh, ru, uk, de, fr, ja.

## Маршрут

Резиденция Санты → Берёзовка → Тихая Долина → Снежноград → обратно к Санте. Это кольцевая линия, ехать от станции до станции около 35 секунд, с ускорением быстрее.
На каждом перегоне свой пейзаж: берёзовая роща с оленями, деревни с мельницей и стогами, горный перевал, праздничный лес.

## День и ночь

Игра начинается ночью. Потом наступает рассвет, короткий зимний день и вечер, и снова ночь. Полный цикл длится 5 минут.

## Как опубликовать на GitHub Pages

1. Создайте на GitHub новый **публичный** репозиторий, например `teplyi-express`.
2. Нажмите **Add file → Upload files** и перетащите **содержимое** этой папки: `index.html`, `game.js`, `i18n.js`, папку `assets` и остальные файлы. Затем нажмите **Commit changes**.
3. Откройте **Settings → Pages**. В разделе **Build and deployment** выберите *Deploy from a branch*, ветку `main` и папку `/ (root)`, затем нажмите **Save**.
4. Через 1–2 минуты игра будет доступна по адресу `https://ВАШ_ЛОГИН.github.io/teplyi-express/`.

## Как запустить на компьютере

Достаточно открыть `index.html` двойным кликом в Chrome, Edge или Firefox. Сервер и установка не нужны.

## Устройство

- Чистый HTML5 Canvas и JavaScript, без библиотек и сборки. Логика лежит в `game.js`, тексты в `i18n.js`.
- Игра занимает весь экран и масштабируется целым множителем без размытия.
- Шрифты Pixelify Sans, DotGothic16 (японский) и Noto Sans SC (китайский) с лицензией OFL подключаются из Google Fonts. Без интернета используется системный шрифт.

## Права

Графика, музыка, звуки и код созданы специально для этой игры, их можно свободно использовать и менять.
Олень и заяц взяты из пака [Animated Wild Animals](https://opengameart.org/content/animated-wild-animals) автора ScratchIO (OpenGameArt, лицензия CC0) и уменьшены вдвое.
